# 03. Интеграция формы с БД (CRUD-операции и обновление UI)

Модуль реализует полную интеграцию пользовательского интерфейса с базой данных SQLite: сохранение новых записей, редактирование существующих, ссылочную целостность и реактивное автоматическое обновление таблиц и карточек реестра.

---

## Реализованные требования ТЗ

1. **Режим добавления (INSERT)**:
   - При нажатии на кнопку **«+ Добавить партнера»** на главной форме открывается пустая карточка партнера (`PartnerEditWindow`).
   - При нажатии **«Сохранить»** формируется параметризованный запрос `INSERT INTO partners (...) VALUES (...)`.
   - Окно закрывается, освобождает модальный фокус, а список партнеров на главной форме автоматически перерисовывается (`refresh_list()`) с отображением вновь созданной записи.
2. **Режим редактирования (UPDATE)**:
   - При двойном клике по карточке партнера или нажатии кнопки **«Изменить»** из БД по первичному ключу `partner_id` подгружаются актуальные данные.
   - Поля карточки автоматически предзаполняются.
   - При сохранении выполняется параметризованный запрос `UPDATE partners SET ... WHERE partner_id = ?`.
   - Главная форма моментально обновляет интерфейс без перезапуска приложения.
3. **Ссылочная целостность (Foreign Key Constraint)**:
   - В SQLite на уровне движка включен режим контроля внешних ключей `PRAGMA foreign_keys = ON;`.
   - Таблица поставок `deliveries` ссылается на `partners(partner_id) ON DELETE RESTRICT`.
   - При попытке удаления партнера, имеющего связанные строки в истории отгрузок, СУБД блокирует операцию и генерирует `sqlite3.IntegrityError`, предотвращая появление «висячих» записей (orphaned records).
