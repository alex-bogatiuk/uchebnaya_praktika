# Учебная практика (21.09.2026): Архитектура многооконного интерфейса, CRUD и UX-безопасность

Программный модуль по развитию корпоративной CRM-системы партнеров: реализация многооконной навигации, формы добавления/редактирования с поддержкой разнородных типов данных, полная синхронизация с СУБД SQLite (CRUD), обеспечение ссылочной целостности и отказоустойчивая обработка исключений с интерактивными диалоговыми окнами.

## Ключевые возможности

1. **Многооконная архитектура**:
   - `MainWindow`: Реестр партнеров со строгим контекстным заголовком `"CRM: Реестр партнеров"`.
   - `PartnerEditWindow`: Модальное окно добавления/редактирования с динамическим заголовком в зависимости от режима.
   - Кнопка «Назад» корректно закрывает окно без сбоев главного интерфейса.
2. **Форма карточки партнера**:
   - Полноценная поддержка всех полей ТЗ: Наименование, Выпадающий список ОПФ (`ttk.Combobox`), Рейтинг (целое неотрицательное), Адрес, Директор, Телефон, Email.
   - Всплывающие подсказки (`ToolTip`) и маски ввода.
3. **CRUD-операции и синхронизация с БД**:
   - Создание (`INSERT`) и изменение (`UPDATE`) записей.
   - Автоматическая подгрузка данных партнера по клику/двойному клику.
   - Реактивное обновление каталога на главной форме.
   - Контроль внешних ключей `FOREIGN KEY ... ON DELETE RESTRICT` (`PRAGMA foreign_keys = ON`).
4. **UX/UI и обработка исключений**:
   - Валидация полей через конструкции `try...except`.
   - 3 типа диалоговых окон (`Error` с инструкцией по исправлению, `Warning` при выходе с несохраненными правками, `Information` при успешном сохранении).
