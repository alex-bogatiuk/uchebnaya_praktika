# 02. Разработка формы добавления и редактирования партнера

Модуль реализует карточку партнера (`PartnerEditWindow`) с поддержкой разнородных типов данных, визуальных подсказок и строгих бизнес-требований.

---

## Реализованные требования ТЗ

1. **Верстка формы со всеми обязательными полями**:
   - `Наименование компании`: Текстовое поле ввода названия юридического лица;
   - `Тип партнера`: Выпадающий список (`ttk.Combobox`) со значениями `['ООО', 'ЗАО', 'ИП', 'ПАО', 'ОАО']` со статусом `readonly` (исключает опечатки пользователя);
   - `Рейтинг`: Целое неотрицательное число (`0`, `1`, `5`, `10` и т.д.);
   - `Юридический адрес`: Текстовое поле для адреса компании;
   - `ФИО руководителя`: Текстовое поле для директора;
   - `Телефон` и `Email`: Текстовые поля с подсказками форматов ввода.
2. **Интерактивные визуальные подсказки (ToolTips и плейсхолдеры)**:
   - При наведении курсора мыши на поле ввода телефона отображается всплывающая подсказка с ожидаемым форматом `+7 (XXX) XXX-XX-XX`.
   - Для поля Email отображается пояснение структуры почтового адреса.
   - Для поля рейтинга выводится пояснение о допустимости только целых неотрицательных чисел.
3. **Стандарты комментирования кода**:
   - Пояснения даны строго в нетривиальных местах алгоритма:
     * Блокировка свободного ввода в ComboBox (`state='readonly'`);
     * Клонирование словаря исходных параметров для отслеживания `dirty state` (несохраненных изменений);
     * Логика привязки модального окна и перехват системного события закрытия (`WM_DELETE_WINDOW`).
