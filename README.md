# Программный комплекс «CRM: Управление партнерами и производственными ресурсами»
## Учебная практика (Сентябрь — Октябрь 2026)

Комплексный программный проект автоматизации работы с партнерами компании, расчета индивидуальных накопительных скидок, калькуляции сырья для производства готовой продукции, многооконного интерфейса (GUI) и обеспечения информационной безопасности.

## Технологический стек

- **Язык разработки**: Python 3.10+ (совместим с Python 3.14).
- **Графический интерфейс (GUI)**: Tkinter + `ttk` (нативный десктопный стек без внешних зависимостей).
- **СУБД**: SQLite 3 с контролем ссылочной целостности (`PRAGMA foreign_keys = ON;`).
- **Тестирование**: Модуль `unittest` стандартной библиотеки Python (13 автоматизированных тестов, 100% PASS).
- **Безопасность**: Защита от SQL-инъекций через строгую параметризацию запросов драйвера.
- **Внешние зависимости**: Отсутствуют. Проект работает на чистом Python стандартной библиотеки (`sqlite3`, `tkinter`, `unittest`, `zlib`, `struct`, `re`, `csv`, `datetime`, `math`).
