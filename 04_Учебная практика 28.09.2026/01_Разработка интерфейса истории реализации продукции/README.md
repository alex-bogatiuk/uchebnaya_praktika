# 01. Разработка интерфейса истории реализации продукции

Модуль реализует специализированное окно истории отгрузок продукции (`PartnerHistoryWindow`) для выбранного партнера компании с аналитикой суммарных объемов и выручки.

---

## Реализованные требования ТЗ

1. **Создание формы PartnerHistoryWindow**:
   - Окно открывается в модальном режиме поверх родительской формы.
   - Отображает фирменный логотип, иконку приложения и структурированную сводку по партнеру.
2. **Строгое соответствие руководству по стилю**:
   - Палитра: чистый белый фон карточек (`#FFFFFF`), фон приложения (`#F1F5F9`), контрастные границы (`#CBD5E1`), акцентный лазурный (`#0284C7`), читаемый темный шрифт (`#0F172A`).
   - Заголовок окна строго по шаблону: `"CRM: История реализации продукции — [Название партнера]"`.
3. **Навигация с передачей идентификатора (`partner_id`)**:
   - При выборе партнера и вызове действия окно получает идентификатор партнера и наименование компании.
   - Кнопка **«← Назад»** корректно закрывает окно без сброса фильтров и состояния главного реестра.
4. **SQL-запрос с объединением таблиц (`INNER JOIN`)**:
   - Запрос объединяет `deliveries` и `products` по внешнему ключу `product_id`.
   - Обязательные поля таблицы:
     * `Наименование продукции`: название номенклатурной позиции;
     * `Количество (шт.)`: отгруженный объем единиц продукции;
     * `Дата продажи`: дата реализации, отформатированная в понятный для человека формат `ДД.ММ.ГГГГ`.
