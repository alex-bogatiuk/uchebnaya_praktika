# 03. Интеграция метода расчета и комплексное тестирование

Модуль реализует визуальный интерфейс калькулятора производственных заказов (`MaterialCalculatorWindow`) со встроенным вызовом алгоритма расчета сырья, валидацией параметров и безопасной обработкой крайних случаев.

---

## Реализованные требования ТЗ

1. **Вывод результата на экран формы**:
   - Форма содержит поля выбора типа продукции и типа сырья, ввода тиража (количества) и геометрических параметров изделия.
   - Стилизованная плашка результата наглядно отображает требуемый объем сырья в штуках/единицах.
2. **Отказоустойчивость и обработка возврата `-1`**:
   - При вводе некорректных данных (отрицательные габариты, количество `<= 0`, несуществующие типы) алгоритм возвращает `-1`.
   - Графический интерфейс перехватывает этот код, меняет цвет информационной плашки на акцентный красный и показывает пользователю понятное диалоговое окно с перечнем вероятных причин ошибки.
   - Исключены любые аварийные падения (`crash / unhandled exceptions`).
3. **Стандарты оформления кода**:
   - Строго одна инструкция на строку;
   - Именование всех функций, методов и свойств в стандарте `snake_case`;
   - Краткие поясняющие комментарии только в ключевых точках интеграции.
