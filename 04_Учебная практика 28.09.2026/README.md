## Ключевые возможности

1. **История реализации продукции**:
   - Окно `PartnerHistoryWindow` с заголовком `"CRM: История реализации продукции — [Название партнера]"`.
   - Запрос с `INNER JOIN` связывает `deliveries` и `products`.
   - Таблица отображает наименование продукции, количество (шт.) и человекочитаемую дату продажи `ДД.ММ.ГГГГ`.
2. **Ядро алгоритма расчета сырья**:
   - Формула: $\lceil \text{quantity} \times \text{param}_1 \times \text{param}_2 \times k_{\text{type}} \times (1 + \text{defect}\% / 100) \rceil$.
   - Безопасный возврат `-1` вместо сбоев при любых некорректных или отрицательных параметрах.
3. **Интерактивный калькулятор**:
   - Окно `MaterialCalculatorWindow` с мгновенным выводом расхода сырья.
   - Защита от аварийных завершений и наглядная индикация ошибок.
4. **Unit-тестирование и безопасность**:
   - 5 обязательных тест-кейсов покрытия граничных условий (округление строго вверх, валидность типов, отрицательные параметры, нулевой тираж).
   - Статический и динамический аудит безопасности на отсутствие уязвимостей SQL Injection.
   - Централизованное логирование в `app.log`.
