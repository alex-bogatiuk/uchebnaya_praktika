# 02. Разработка ядра алгоритма расчета материалов

Модуль реализует математическое ядро калькулятора расхода сырья для производства готовой продукции с учетом габаритных коэффициентов и технологических потерь (процента брака).

---

## Математическая модель метода

1. **Входные параметры (5 параметров)**:
   - `product_type_id (int)`: Идентификатор типа продукции;
   - `material_type_id (int)`: Идентификатор типа материала;
   - `quantity (int)`: Количество единиц продукции к выпуску (целое положительное число);
   - `param_1 (float)`: Первый вещественный геометрический параметр изделия (`> 0`);
   - `param_2 (float)`: Второй вещественный геометрический параметр изделия (`> 0`).
2. **Формула расчета**:
   $$\text{Базовый расход на 1 ед.} = \text{param}_1 \times \text{param}_2 \times \text{Коэффициент типа}$$
   $$\text{Общий чистый расход} = \text{Базовый расход на 1 ед.} \times \text{quantity}$$
   $$\text{Итоговый расход с учетом брака} = \text{Общий чистый расход} \times \left(1 + \frac{\text{Процент брака}}{100}\right)$$
   $$\text{Результат} = \lceil \text{Итоговый расход с учетом брака} \rceil \quad (\text{math.ceil})$$
3. **Обработка исключительных ситуаций и ошибок ввода**:
   - Метод строго возвращает `-1` (вместо падения программы или выброса исключений):
     * при передаче несуществующего `product_type_id`;
     * при передаче несуществующего `material_type_id`;
     * при неположительных параметрах изделия (`param_1 <= 0` или `param_2 <= 0`);
     * при количестве продукции `quantity <= 0`.
4. **Стандарты оформления кода**:
   - Строго одна команда на строку;
   - Стиль именования переменных и функций — `snake_case`;
   - Краткие комментарии размещены исключительно в нетривиальных местах алгоритма.
