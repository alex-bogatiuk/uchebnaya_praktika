# 4. Проверочные SQL-запросы (эмуляция бэкенда)

Файл `queries.sql` содержит ровно три сценария из задания.

## Запрос 1 — список партнеров

Выводит партнеров:

- с сортировкой по `company_name`;
- с количеством их доставок;
- с использованием `LEFT JOIN` и `COUNT`.

`LEFT JOIN` нужен для того, чтобы в результате оставались партнеры, у которых пока нет доставок.

## Запрос 2 — транзакционное добавление

В одном блоке:

```text
BEGIN
  -> INSERT partner
  -> INSERT first delivery
COMMIT
```

Если запись доставки нарушит ограничения БД, транзакция не сможет быть успешно зафиксирована целиком.

## Запрос 3 — история реализации за период

Выводит для конкретного партнера:

- название товара;
- дату отгрузки;
- количество в штуках;
- цену единицы;
- итоговую сумму `quantity * unit_price`.

В демонстрационной версии используется партнер `1` и период с `2026-03-01` по `2026-03-31`. В реальном backend-приложении эти значения передаются параметрами.
