# 3. Подготовка данных и импорт (ETL)

## Исходные файлы

В папке `source/` находятся:

- `import_partners.csv` — партнеры;
- `import_sales.txt` — продажи/отгрузки.

## Найденные аномалии

ETL обрабатывает следующие типы аномалий:

1. лишние пробелы в названиях;
2. разные форматы телефонных номеров;
3. пустые значения;
4. разные форматы дат (`YYYY-MM-DD` и `DD.MM.YYYY`);
5. возможные дубликаты `partner_id`, ИНН, email и `sale_id`;
6. некорректные количества и суммы;
7. ссылки на отсутствующих партнеров.

В текущем наборе данных строка продажи `sale_id = 104` ссылается на `partner_id = 4`, которого нет в исходном файле партнеров. Такая запись не загружается в основную БД и сохраняется в `cleaned/rejected_sales.csv`.

## Преобразование данных

Скрипт `etl.py`:

- очищает строки;
- нормализует email и телефоны;
- приводит даты к `YYYY-MM-DD`;
- выполняет проверки дубликатов;
- выделяет уникальные товары в таблицу `products`;
- преобразует продажи в `deliveries`;
- рассчитывает `unit_price = total_amount / quantity` с точностью до 4 знаков;
- сохраняет отклоненные строки отдельно.

Запуск из корня репозитория:

```bash
python 03_etl/etl.py
```

После запуска создаются:

```text
03_etl/cleaned/
├── partners.csv
├── products.csv
├── deliveries.csv
├── rejected_partners.csv
├── rejected_sales.csv
└── etl_report.txt
```

## Импорт в PostgreSQL

Перед импортом необходимо выполнить DDL:

```bash
psql -d your_database -f 02_ddl/schema.sql
```

Затем:

```bash
psql -d your_database -f 03_etl/load_data.sql
```

В `load_data.sql` используется команда `\copy`.

## Проверка импорта

```bash
psql -d your_database -f 03_etl/checks.sql
```

Ожидаемые результаты:

| Таблица | Количество строк |
|---|---:|
| `partners` | 3 |
| `products` | 3 |
| `deliveries` | 4 |

Исходных продаж 5, но одна запись отклонена из-за нарушения ссылочной целостности.
