# 01. Инфраструктура данных и ETL (База данных в 3NF)

Модуль реализует чистое реляционное хранилище данных в третьей нормальной форме (3NF) и автоматизированный ETL-конвейер первичной обработки, валидации и загрузки сырых данных.

---

## Реализованные требования ТЗ

1. **Проектирование схемы в 3NF**:
   - `partners`: Основные сведения о контрагентах (наименование, ОПФ, ИНН, email, телефон, адрес, рейтинг);
   - `products`: Справочник товарной номенклатуры с уникальными наименованиями;
   - `sales_history`: Фактическая история реализации с внешними ключами `FOREIGN KEY (partner_id)` и `FOREIGN KEY (product_id)` с запретом каскадного удаления (`ON DELETE RESTRICT`);
   - Вспомогательные нормализованные таблицы `product_types` и `material_types` для калькулятора сырья.
2. **DDL-скрипт (`schema.sql`)**:
   - Ограничения `NOT NULL` для критических атрибутов;
   - Ограничение `UNIQUE` для ИНН, Email и наименований товаров;
   - Тип `REAL/DECIMAL` для стоимостных показателей;
   - Единый стиль именования идентификаторов: `snake_case`.
3. **ETL-конвейер (Extract, Transform, Load)**:
   - **TRIM**: Очистка всех текстовых атрибутов от хвостовых пробелов и непечатных знаков;
   - **Нормализация дат**: Преобразование разнородных форматов (`15.03.2026` $\to$ `2026-03-15`) к стандарту ISO-8601;
   - **Фильтрация аномалий**: Устранение строки с несуществующим `partner_id=4` (запись продажи 104) с экспортом в `cleaned/rejected_sales.csv`;
   - **Аналитический отчет**: Формирование `cleaned/etl_report.txt` с детализацией количества обработанных строк и причин отбраковки.
