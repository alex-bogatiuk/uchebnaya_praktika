# 04. Автоматизированное тестирование, аудит безопасности и UX

Финальный модуль комплексной проверки и сдачи программного решения: автоматизированные Unit-тесты бизнес-логики, статический и динамический аудит безопасности (SQL Injection), интерактивная защита UX при сбоях и главная исполняемая точка входа приложения `main.py`.

---

## Реализованные требования ТЗ

1. **Модульные тесты (Unit Testing)**:
   - Комплекс из не менее 5 обязательных тест-кейсов для калькулятора расхода сырья:
     * Базовый расчет с эталонным результатом (100 шт $\to$ 331 ед.);
     * Округление дробного расхода строго в большую сторону (`math.ceil`);
     * Возврат `-1` при передаче некорректных ID типов продукции или сырья;
     * Возврат `-1` при отрицательных или нулевых размерах изделия;
     * Возврат `-1` при неположительном тираже продукции (`quantity <= 0`);
     * Защита от передачи булевых типов данных (`bool`).
2. **Аудит безопасности (Защита от SQL-инъекций)**:
   - Статический сканер исключает использование динамических f-строк, строковой конкатенации (`+`) или форматирования `.format()` внутри SQL-вызовов;
   - Динамический тест подтверждает, что вредоносные полезные нагрузки (`' OR '1'='1`, `'; DROP TABLE...`, `Admin'--`) экранируются драйвером СУБД SQLite и сохраняются как безопасные строковые литералы.
3. **Обработка исключений и интерактивные диалоговые окна (MessageBox)**:
   - Конструкции `try...except` перехватывают ошибки валидации и сбои СУБД;
   - **Ошибка (`Error`)**: Выводит понятный текст и пошаговое руководство по исправлению;
   - **Предупреждение (`Warning`)**: Запрашивает подтверждение выхода при наличии несохраненных правок в форме;
   - **Информация (`Information`)**: Подтверждает успешное сохранение или регистрацию контрагента.
4. **Главный файл запуска системы (`main.py`)**:
   - `python main.py` — Запуск полнофункционального десктопного GUI;
   - `python main.py --cli` — Консольный просмотр реестра партнеров;
   - `python main.py --calc` — Автономный калькулятор сырья;
   - `python main.py --test` — Запуск автоматизированного набора тестов;
   - `python main.py --audit` — Запуск аудита безопасности.
