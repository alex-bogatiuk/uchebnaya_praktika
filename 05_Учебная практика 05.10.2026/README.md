# Учебная практика (05.10.2026): Инфраструктура 3NF, ETL, бизнес-логика и финальная сборка CRM

Итоговый программный проект учебной практики: развертывание реляционной базы данных в 3-й нормальной форме (3NF), разработка ETL-конвейера импорта и очистки данных, реализация ядра бизнес-логики (скидки и расчет сырья), многооконный эргономичный графический интерфейс (GUI), автоматизированное тестирование и аудит безопасности.

## Резюме ключевых подсистем

1. **Модуль 01 (Инфраструктура данных и ETL)**:
   - Реляционная схема 3NF с ограничениями целостности `FOREIGN KEY (partner_id, product_id) ON DELETE RESTRICT`.
   - Автоматическая очистка: удаление пробелов (TRIM), нормализация дат к `ГГГГ-ММ-ДД` (`YYYY-MM-DD`).
   - Фильтрация битых внешних ключей (отсечение продажи с несуществующим партнером `partner_id=4`).
2. **Модуль 02 (Ядро бизнес-логики)**:
   - Расчет индивидуальных накопительных скидок по шкале (`0%`, `5%`, `10%`, `15%`).
   - Калькулятор потребности сырья по формуле: $\lceil \text{quantity} \times \text{param}_1 \times \text{param}_2 \times k_{\text{type}} \times (1 + \text{defect}\% / 100) \rceil$.
   - Безопасный возврат `-1` при любых некорректных входных данных.
3. **Модуль 03 (Пользовательский интерфейс и навигация)**:
   - Главная форма `MainWindow` со списком партнеров, логотипом компании и фирменной иконкой.
   - Карточка добавления/редактирования `PartnerEditWindow` со всеми полями, валидацией, плейсхолдерами и всплывающими подсказками (`ToolTips`).
   - Окно истории отгрузок `PartnerHistoryWindow` с таблицей продаж (`JOIN`-запрос к `sales_history` и `products`).
   - Реактивная синхронизация данных: автоматическое обновление реестра при сохранении карточки.
4. **Модуль 04 (Тестирование, безопасность и UX)**:
   - Комплекс модульных тестов (`unittest`) для всех крайних случаев бизнес-логики.
   - Статический и динамический аудит безопасности на защищенность от SQL-инъекций.
   - Диалоговые окна трех типов (`Error`, `Warning`, `Information`).
   - Единая точка запуска `main.py` со вспомогательными CLI-ключами (`--cli`, `--calc`, `--test`, `--audit`).

## Быстрый запуск

### 1. Подготовка и очистка данных (ETL)
```bash
python "01_Инфраструктура данных и ETL (База данных в 3NF)/etl.py"
```

### 2. Запуск десктопного приложения (GUI)
```bash
python "04_Автоматизированное тестирование, аудит безопасности и UX/main.py"
```

### 3. Просмотр реестра в терминале (CLI)
```bash
python "04_Автоматизированное тестирование, аудит безопасности и UX/main.py" --cli
```

### 4. Запуск всех тестов
```bash
python "04_Автоматизированное тестирование, аудит безопасности и UX/main.py" --test
```

### 5. Запуск аудита безопасности
```bash
python "04_Автоматизированное тестирование, аудит безопасности и UX/main.py" --audit
```
