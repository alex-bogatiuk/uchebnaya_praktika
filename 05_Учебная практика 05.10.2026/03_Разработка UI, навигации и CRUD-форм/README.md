# 03. Разработка UI, навигации и CRUD-форм

Модуль объединяет все компоненты пользовательского интерфейса десктопного приложения: главный реестр, модальные карточки добавления и редактирования партнеров, экран истории продаж и механизмы реактивной синхронизации с базой данных.

---

## Реализованные требования ТЗ

1. **Главная форма (`MainWindow`)**:
   - Автоматическая подгрузка каталога партнеров из SQLite (`partners.db`);
   - Отображение иконки приложения в заголовке и корпоративного логотипа в шапке;
   - Заголовок окна: `"CRM: Реестр партнеров компании"`;
   - Карточки партнеров содержат тип и название, ФИО директора, телефон, рейтинг, объем продаж и вычисленный индивидуальный процент скидки.
2. **Форма добавления/редактирования (`PartnerEditWindow`)**:
   - Полный перечень полей: Наименование, Выпадающий список типа партнера (`ttk.Combobox`), Рейтинг (только целое неотрицательное число), Адрес, Директор, Телефон, Email;
   - Настроены всплывающие подсказки (`ToolTips`) с форматами ввода.
3. **Окно истории отгрузок (`PartnerHistoryWindow`)**:
   - Отображает таблицу реализации продукции конкретного контрагента с JOIN-запросом;
   - Заголовок окна: `"CRM: История реализации продукции — [Название партнера]"`;
   - Обязательная кнопка **«← Назад»** для возврата на главную форму без потери состояния.
4. **Реактивная синхронизация данных**:
   - При создании или изменении партнера изменения фиксируются в БД (`INSERT` / `UPDATE`), окно карточки закрывается, а каталог на главной форме автоматически перерисовывается.
