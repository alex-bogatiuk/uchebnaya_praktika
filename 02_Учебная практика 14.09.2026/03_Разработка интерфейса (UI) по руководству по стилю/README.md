# 03. Разработка интерфейса (UI) по руководству по стилю

## Описание модуля

Модуль реализует визуальный интерфейс для менеджеров компании («Мастер Пол») для удобного просмотра каталога партнеров, их контактных данных, рейтингов и рассчитанных индивидуальных скидок.

Интерфейс спроектирован в точном соответствии с макетом [`Screenshot_2.png`] и требованиями ТЗ:
1. **Заголовок окна / страницы**: «CRM: Список партнеров и скидок».
2. **Иконка приложения**: установлена уникальная иконка в углу окна из каталога `resources/` (`icon.png`, `icon.ico`).
3. **Логотип компании**: отображается в шапке окна из каталога `resources/` (`logo.png`).
4. **Главный макет (список карточек партнеров)**:
   - Каждая карточка обрамлена аккуратной рамкой с отступами.
   - Слева (4 строки):
     1. `Тип | Наименование партнера` (полужирный шрифт, размер 12–14pt);
     2. `Директор: ФИО руководителя`;
     3. Номер контактного телефона;
     4. `Рейтинг: X`.
   - Справа:
     - Крупный процент рассчитанной накопительной скидки (например, `10%`, `15%`, `0%`).

---

## Структура модуля

- [`resources/`]:
  - `logo.png` — корпоративный логотип компании;
  - `icon.png` / `icon.ico` — иконки приложения для окна и ярлыка.
- [`generate_resources.py`]: генератор ресурсов PNG/ICO на базе стандартных библиотек Python.
- [`ui_desktop.py`]: десктопное приложение на Tkinter (автономное, не требует pip).
- [`web/`]:
  - `index.html` — семантическая разметка с карточками партнеров;
  - `style.css` — стилизация по макету Screenshot_2;
  - `app.js` — клиентская интерактивная логика и асинхронный fetch;
  - `server.py` — локальный HTTP и REST API сервер.

---

## Запуск интерфейса

### Вариант 1: Десктопное приложение (Tkinter)
```bash
python ui_desktop.py
```

### Вариант 2: Веб-интерфейс с REST API
```bash
python web/server.py
```
После запуска откройте браузер по адресу:  
[http://localhost:8000/web/index.html](http://localhost:8000/web/index.html)
