# 04. Наполнение интерфейса, отладка и стресс-тестирование

## Описание модуля

Финальный интеграционный этап сборки проекта:
1. **Связывание UI и базы данных**: окно приложения наполняется актуальными данными партнеров с динамическим расчетом скидок в реальном времени.
2. **Отладка и отказоустойчивость**:
   - Гарантирована корректная обработка партнеров **без истории продаж** (`SUM(quantity) IS NULL` или `0`). В этом случае скидка строго равна `0%`, а приложение работает стабильно без сбоев (`TypeError`, `NullPointerException`, `AttributeError`).
   - Обеспечена корректная обработка неполных данных (отсутствие телефона, email, директора, рейтинга).
3. **Стресс-тестирование**:
   - Нагрузочный тест на 1 000 партнеров и 10 000 записей отгрузок.
   - Время отклика SQL-агрегации и расчета скидок: **менее 0.01 секунды** (0.0071 с).
   - Подтверждена 100% стабильность работы под нагрузкой.

## Инструкция по запуску

### 1. Запуск настольного приложения (GUI)
```bash
python main.py
```
Открывает графическое окно Tkinter с логотипом компании, иконкой приложения и карточками партнеров по макету [`Screenshot_2.png`].

### 2. Консольный режим (CLI)
```bash
python main.py --cli
```
Выводит форматированную сводную таблицу в консоль со всеми партнерами, объемами и процентами скидок.

### 3. Запуск веб-версии (Web GUI + REST API)
```bash
python main.py --web
```
Запускает локальный HTTP-сервер на `http://localhost:8000/web/index.html`.

### 4. Запуск стресс-теста
```bash
python main.py --test
```
или
```bash
python stress_test.py
```
