# Учебная практика (14.09.2026): CRM партнеров и расчет индивидуальных скидок

Учебный программный проект по разработке ядра бизнес-логики, интеграции с базой данных через SQL-агрегацию, созданию графического интерфейса по руководству по стилю и стресс-тестированию отказоустойчивости системы.

---

## Бизнес-требования

Система обеспечивает:
1. **Расчет индивидуальной накопительной скидки партнера**:
   - объем < 10 000 ед. — `0%`;
   - объем от 10 000 до 49 999 ед. — `5%`;
   - объем от 50 000 до 299 999 ед. — `10%`;
   - объем от 300 000 ед. и более — `15%`.
2. **Динамическую агрегацию данных из БД**:
   - запрос с `LEFT JOIN` и `SUM(quantity)` по истории отгрузок (`deliveries` / `sales_history`);
   - гарантированную обработку партнеров с 0 продаж (`NULL`) без сбоев системы.
3. **Пользовательский интерфейс по руководству по стилю**:
   - точное соответствие макету `Screenshot_2.png`;
   - отображение типа и наименования партнера, ФИО директора, телефона, рейтинга и процента скидки;
   - корпоративная шапка с логотипом компании и иконка приложения.
4. **Отказоустойчивость и высокую производительность**:
   - стресс-тест на 1 000 партнеров и 10 000 поставок с временем отклика < 0.01 сек.

## Используемые технологии

- **Язык**: Python 3.10+ (совместим с Python 3.14).
- **Стандартная библиотека**: `sqlite3`, `tkinter`, `unittest`, `http.server`, `zlib`, `struct`.
- **База данных**: SQLite (автономная) / PostgreSQL (полная совместимость со схемой 07.09.2026).
- **Веб-стек**: HTML5, Vanilla CSS, JavaScript (Fetch API).
- **Внешние зависимости**: не требуются (запускается на чистом Python).

## Быстрый запуск

### 1. Запуск десктопного графического интерфейса (GUI)
Из папки `04_Наполнение интерфейса, отладка и стресс-тестирование`:
```bash
python main.py
```

### 2. Запуск консольного просмотра (CLI)
```bash
python main.py --cli
```

### 3. Запуск веб-интерфейса (браузер)
```bash
python main.py --web
```
После запуска перейти по адресу: `http://localhost:8000/web/index.html`

### 4. Запуск тестов всех модулей

**Модуль 01 (Ядро скидок, 100% покрытие граничных условий):**
```bash
python "01_Разработка ядра бизнес-логики (Расчет скидки)/test_discount.py"
```

**Модуль 02 (Интеграция с БД и SQL-агрегация):**
```bash
python "02_Интеграция с БД и агрегация данных (SQL + Backend)/test_database.py"
```

**Модуль 04 (Стресс-тестирование и проверка обработки NULL):**
```bash
python "04_Наполнение интерфейса, отладка и стресс-тестирование/stress_test.py"
```
