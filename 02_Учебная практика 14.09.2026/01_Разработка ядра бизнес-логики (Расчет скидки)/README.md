# 01. Разработка ядра бизнес-логики (Расчет скидки)

## Описание модуля

Данный модуль содержит чистую изолированную функцию бизнес-логики для вычисления индивидуальной накопительной скидки партнера на основе суммарного объема приобретенной им продукции за весь период сотрудничества.

### Критерии расчета скидки (по ТЗ)

| Суммарный объем продаж (ед.) | Процент скидки | Пояснение |
|---|:---:|---|
| **< 10 000** | **0%** | Базовый уровень без скидки |
| **10 000 — 49 999** | **5%** | Начальная скидочная категория |
| **50 000 — 299 999** | **10%** | Оптовая скидочная категория |
| **>= 300 000** | **15%** | Максимальная партнерская скидка |

## Тестирование и верификация

Тесты реализованы на базе стандартного модуля `unittest` в файле [`test_discount.py`].

### Проверяемые граничные значения (по ТЗ):
- `9 999` ед. -> `0%`
- `10 000` ед. -> `5%`
- `49 999` ед. -> `5%`
- `50 000` ед. -> `10%`
- `299 999` ед. -> `10%`
- `300 000` ед. -> `15%`

А также:
- Нулевой объем (`0` ед. -> `0%`);
- Сверхбольшой объем (`1 000 000` ед. -> `15%`);
- Отрицательные объемы (`-1`, `-10 000` -> `ValueError`);
- Некорректные типы аргументов (`str`, `float`, `None`, `bool` -> `TypeError`).

Покрытие кода тестами: **100%**.
